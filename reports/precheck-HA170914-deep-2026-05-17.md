### 3.1 Issue 内容摘要

> `.devcontainer/devcontainer-lock.json` 文件目前未被跟踪（不在 `.gitignore` 中，只是从未被 git add）。该文件固定 devcontainer 特性的精确版本，就像 `package-lock.json` 一样。没有它，不同时间构建容器的贡献者可能得到不同的 ghcr.io 镜像版本。

### 3.2 修复方案

```
1. git clone https://github.com/home-assistant/core.git
2. cd core && code . (在 DevContainer 中打开)
3. 或手动运行: devcontainer build --workspace-folder .
4. 生成的 .devcontainer/devcontainer-lock.json 会自动出现
5. git add .devcontainer/devcontainer-lock.json
6. git commit -m "Add devcontainer lockfile for reproducible builds"
7. 创建 PR
```
